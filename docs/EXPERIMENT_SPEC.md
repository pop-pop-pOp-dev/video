## 3. 固定实例观察

- 最近 8 秒，名义 2 FPS，实际时间戳，最多 16 帧；不读查询时刻后的帧。
- 冻结 RT-DETR-R50 COCO 检测器，锁定实际实现、权重版本与预处理哈希。
- 每帧最多 8 个实例；最多 16 个轨迹对候选；至少一端为人物。
- 关联基于固定 IoU、外观相似度和短时匹配规则；阈值从已存在实现继承或在冻结前写死，不按测试结果修改。
- 检测器和冻结视觉特征按唯一采样帧计算一次，重叠8秒窗口复用观测。跟踪必须前向因果执行；禁止用未来帧回填过去轨迹、双向平滑或轨迹插值。检测时的时间归一化只用当前前缀，不用全视频未来时长。
- 学生输入包含局部、联合区域、全景视觉特征，归一化几何及带符号时间变化。
- 从同一次冻结 SigLIP patch 特征按区域池化；不默认增加每个候选裁剪的独立 SigLIP forward。与既有预处理不兼容时，额外计算必须计入预算。
- 两层时序编码，维度 384，输出最多 16 个新增视觉 token；所有训练组架构与参数逐项相同。
- 失败和无候选状态显式记录；不存在候选时新增分支旁路，不把它解释为正常。

四个时间格点分别覆盖该 8 秒窗口的四个顺序区间。候选关系×时间最多为 16×4=64 个单元，加一项空证据，共最多 65 维。无效单元使用掩码，不参与 softmax。轨迹编号仅为局部索引，不是来源身份。

## 4. 训练期教师：固定算法

### 4.1 正常参照检索与过程距离

检索只使用背景外观、对象类别组成和静态兼容性，不使用待比较的运动差异。背景描述尽量从检测区域外的冻结特征构造；无法获得可靠背景时记录状态，不用人工补标。

每个目标窗口选择三个不同来源族的正常参照；排除自身、重复、重叠及同来源媒体。参照对与目标对按对象类别和初始归一化几何确定匹配，不根据目标过程差异选择“最相似动作”。匹配不足的候选单元无效。

过程描述使用起止关系几何、带符号的几何变化、相对速度，以及局部/联合区域的视觉变化；不得只保留运动范数或峰值。各特征块使用参照侧正常数据的稳健尺度标准化，等权组合。实际字段顺序、尺度下限与数值 epsilon 写入配置并哈希。

同一对轨迹的四格过程用单调、禁止时间反转的短序列对齐比较；路径允许水平、垂直、对角步，但固定端点并限制连续水平或垂直步不超过一次。缺失格点不得用零特征伪造。对齐规则是辅助比较，不宣称跨视频真实动作阶段对应。

对每个有效关系—时间单元，得到三个正常参照的距离，取中位数记为 d[e,t]。统计窗口整体强度 M=max(d[e,t])。所有组使用完全相同的原始距离、掩码与参照。

### 4.2 来源互斥交叉校准

将增量训练来源分成五折。对目标折 k：
- 目标 Q 为第 k 折；
- 正常校准 C 为第 (k+1) mod 5 折；
- 参照 R 为其余三折中的正常窗口。
Q、C、R 的来源族互不重叠。Q 与 C 用相同 R 计算过程距离及 M。全量循环五次，为固定训练样本生成 out-of-source 教师；不训练五个额外大模型。

对目标窗口，在 C 中以相同静态上下文检索规则选取最多 128 个兼容正常窗口，至少需要 64 个窗口、16 个来源族，并限制每个来源最多四个。候选数量及有效时段数量纳入静态支持描述，以减小最大值随候选数量增长的混淆。兼容距离阈值由 R 中正常窗口留一来源检索距离的第95百分位按固定算法产生，不用测试效果调阈值。

不足时只屏蔽该样本的辅助损失，不把拒绝蒸馏写成“空证据/正常”。另报告各数据集、关系类型、正常/异常的覆盖率。

经验尾部比例：p=(1 + 正常校准窗口中 M_normal >= M_target 的个数)/(n+1)。
证据质量：a=clip((0.05-p)/0.05, 0, 1)。
位置分布：pi=masked_softmax(d / 1.0)。
教师分布：q[empty]=1-a，q[e,t]=a*pi[e,t]。

第95百分位约束针对最终聚合的窗口统计量 M，而不是64个单元逐个阈值。该经验校准不具有自动成立的分布无关/条件覆盖保证，也不是异常概率；部署误报率不能据此宣称为5%。

### 4.3 学生接口与损失

学生从单视频预测 a_hat 与 pi_hat。证据位置权重必须进入实际 resampler 的聚合，非空质量进入新增残差分支；禁止只有一个与下游 token 脱离的辅助分类头。仍需通过实际扰动验证 Slow 是否利用这些 token。

完整蒸馏：
L_aux = KL(Bern(a) || Bern(a_hat)) + a * KL(pi || pi_hat)。
这是65维联合分布KL的分解，不是新增数学定理。KL使用FP32和固定数值保护。

辅助损失仅施加在6,000个检测前缀的合法8秒窗口。2,000条描述指令只使用原始描述目标，不构造任何新的攻击、盗窃等文本真值。这一限制减少长视频教师构造和跨粒度标签混淆。

描述任务仍覆盖官方媒体完整已观察范围：按8秒分块编码，并通过固定16-query聚合形成16个token；所有块均参与，附加时间位置。不得只取最后8秒、最高分块或缩短官方视频。长输入完整forward/backward必须验收。

教师参照视频、校准分布、标签及来源身份都不进入部署学生。无效观测掩码可以进入学生；来源字符串不可以。

## 6. 训练配方

8,000个固定样本：6,000检测前缀、2,000合法描述；检测按数据集和原有正常/异常标签平衡并限制来源集中。参照来自固定训练样本支持的正常窗口；任何额外只读校准观察须单独披露清单，不能暗中增加监督。

BF16；microbatch=1；梯度累积=8；1,000次有效optimizer更新；新模块LR=1e-4；Slow LoRA LR=5e-6；AdamW；weight_decay=.01；warmup=50 updates；梯度裁剪=1.0。主损失沿用原任务实现；辅助权重=.1。无效辅助项记零，分母使用整个batch，不随每步教师成功数改变。

只用最终checkpoint。每个正式run从同一个原Stage2起点加载，不从上一组继续训练。每个seed确定相同数据排列和相同新增模块初始化，便于配对比较。冒烟训练使用独立副本且不进入正式起点。不得按开发或测试得分提前停止、重新选择种子、修改学习率或追加扫描。

每50个有效更新原子保存完整可恢复状态：增量参数、optimizer、scheduler、RNG、sampler顺序、update计数、代码/配置/数据/教师哈希。只保留两份滚动恢复副本和正式final；不删除原始项目权重。

## 9. 低附加计算的机制诊断

固定256个开发前缀，按来源和正常/异常分层；不足时使用全部并披露实际数，不用测试挑选。所有组在同一集合诊断。

- 教师诊断：正常尾部响应、a分布、有效参照覆盖、关系/时间边际、候选数依赖、关联失败分层。只用现有标注评价，不声称关系真值准确率。
- 时间和关系对齐：对学生pi做时间格/关系索引置换，保持a和pi的数值集合/熵；教师pi仅用于预定机制诊断，不作为正式模型输入。检查下游判断、原目标loss及固定解码结果的变化。
- 对照扰动：去掉新增分支、打乱关系—时间权重、等量随机扰动。敏感不等于正确；需要F相对S/A的差异与真实标签表现共同解释。
- 低成本代数检查：统一归一化坐标平移下相对几何应不变；加整体平移轨迹检查相对速度；检查反转过程是否保留/改变带符号描述。仅称几何不变性检查。
- 背景特征扰动仅在已验证的特征层进行，目标是观察无关背景依赖，不宣称真实像素场景干预或标签应翻转。兼容背景/全景仍可提供必要语境。
- 完整预测复用：正常误报、异常召回、类别、短事件、长视频、小目标、无候选、关联失败、参照不足。保留Fast触发标志，单独报告触发子集。冻结Fast时不能声称修复所有从未触发的漏检。
- 冷缓存真实端到端延迟、峰值显存、检测器/过程编码成本、Slow调用次数；与缓存评测吞吐分开。冻结触发若使调用量相同，应如实报告。

## 10. 首日预算验收

所有数字是排期配额，非已测吞吐。

H100：正式训练<=120h，准备/容量<=12h，评测<=60h，预留48h；总租约<=240h。双4090：公共准备约64 GPUh，正式评测约448 GPUh，诊断约24 GPUh；按消息时间理论余量约121.6 GPUh，不再写136h。

12,000次正式更新装入120h要求含开销平均<=36秒/update。如果估算还要额外加25%安全系数，裸测均值需约<=28.8秒/update。按短/中/长真实输入分层计时，覆盖长视频描述、完整生成上限、保存重载、缓存命中/未命中、H100与4090分别测量。

对每个作业记录设备资格、显存、预估时间上界、依赖、可恢复点和截止时间。算力预算要检查H100与每张4090的独立时间线，以及CPU解码、传输、统计和串行关键路径；不能把H100小时与4090小时直接相加当等效算力。

第一天输出resource_feasibility.json和机器排程。预测不足时只能优化等价缓存、去重复解码、合法并发和H100评测分配。不能缩测试、缩生成上限、减seed却标原矩阵完成；资源仍不足必须首日记录缺口。已经授权的资源不足不意味着自动获得增租权限。

新增存储工作配额：派生媒体100GiB，紧凑观测80GiB，公共分块缓存40GiB，增量权重/恢复状态45GiB，预测/日志15GiB，至少20GiB空闲。此为可调整内部配额，实际总量不可越界。对可重算缓存使用LRU；不以磁盘不足为理由删除原数据。原始SigLIP全patch及每个长前缀快照不得全量常驻。

## 12. 24×7执行：进程持续，不要求对话永久持续

控制层由持久任务队列和独立worker组成；Codex处理实施、有限修复和审核。稳定训练/推理不依赖Codex每分钟在线。

单一控制节点管理本地SQLite任务库或等价事务数据库；远端H100 worker经受控接口领取租约，不把SQLite WAL文件放到不可靠共享网络盘。作业状态：PENDING、RUNNING、RETRY_WAIT、SUCCEEDED、BLOCKED。每个作业有唯一键、依赖、输入哈希、输出校验和、重试次数和lease。状态更新事务化，结果先临时写入再原子提交。

工程角色限两个：实施agent和独立审查agent，使用隔离worktree；只有通过验收的commit进入运行。禁止多个agent改同一训练文件。正式运行使用只读版本/容器镜像，不执行工作区未提交变化。

普通Python/调度器按依赖派发已验证训练及推理。Codex一次只完成一个有验收条件的里程碑或有证据的修复；完成后提交状态，由supervisor决定下一项。这样Codex会话结束或额度短缺，不会主动杀掉已启动的GPU worker。

每60秒heartbeat；进度超时按max(30分钟,5×实测p99作业进度间隔)判断，并先核实是否正常长输入。训练每50更新保存；推理按媒体/问题事务保存。单任务同一瞬时错误最多三次重试，固定退避5/20/60分钟。达到上限标BLOCKED并继续无依赖任务，不无限烧卡。

错误处理：
- I/O/网络短暂失败：原任务同配置恢复；无额外消费授权不得换付费服务。
- 4090显存不足：转预授权H100、CPU offload或已验收等价执行；不得截断媒体。H100路径同样必须实测。
- NaN或错误梯度：阻塞受影响训练，生成最小复现，由修复agent处理；不能自动改变学习率使曲线好看。
- 缓存坏块：校验失败则失效重算；不能跨模型复用Slow状态。
- 测试泄漏、原权重哈希不符、预算/磁盘硬上限：保护性阻塞；不能以“无中止”指令绕过。
- Codex限流：按官方额度和重试规则退避，已验证worker继续；不轮换账号规避额度。
- 重启/租约终止：从已提交状态恢复；H100租约结束前排出必要保存与导出时间。

CLI须先记录codex --version并核验本地帮助。官方非交互模式支持codex exec、JSONL输出和会话恢复；在已配置好的受控workspace中可用如下单次工作单元：

```bash
RUN_ID="$(date -u +%Y%m%dT%H%M%SZ)-$$"
mkdir -p "runlogs/$RUN_ID"
codex --ask-for-approval never --sandbox workspace-write exec \
  --json --output-last-message "runlogs/$RUN_ID/last_message.txt" \
  '读取AGENTS.md和冻结实验规格。只完成一个已就绪里程碑，运行验收，记录产物哈希并更新状态。已授权范围内不请求重复确认；不得改变科研配置、读取测试指标、扩大权限或超预算。' \
  > "runlogs/$RUN_ID/codex_events.jsonl"
```

这是工作单元示例，不是完整supervisor，也不是本项目已执行的命令。GPU、网络、挂载和容器权限要在正式运行前合法配置；never不会赋予额外权限。禁止默认使用全权限绕过沙箱。密钥不进入Git、日志、模型或训练worker环境。

每天由本地程序生成两次状态摘要：模型完成数、预测覆盖、实际设备小时、磁盘余额、失败项、剩余排程风险；不需要LLM读取海量训练日志。用户本次只请求方案，未在此会话创建提醒或启动远程守护进程。

## 13. 必须交付的目录与完成条件

推荐结构：
- AGENTS.md：边界、入口、不可更改项；
- docs/EXPERIMENT_SPEC.md：本规格；
- configs/frozen.yaml：冻结数值和哈希；
- manifests/：来源族、训练8000、参照/校准、官方媒体/问题；
- state/：任务库、预算与状态；
- runs/：12个正式run的final和恢复状态；
- predictions/：13模型完整预测及失败原因；
- metrics/：只允许盲评解锁后的输出；
- reports/：完整性、成本、统计、机制诊断；
- paper/：方法、实验、局限、图表；
- archive/：旧纲及变更证据，不含被删除的原始材料。

最终必须同时输出：主结果表、F-A/U/S机制对照表、三粒度描述表、覆盖与失败分层表、端到端成本表；方法图、效应量/CI图、正常校准图、证据利用诊断图；全部预测、配置、增量权重、环境版本、运行命令、统计实现及复现README。

completion_report.json必须区分：
- complete：12/12正式训练、13/13全量评测、完整分母、统计、成本、复现全部通过；
- incomplete：任何缺失项明确列出，不将失败和缺失填成成功；
- scientific_outcome：positive / mixed / negative / uninformative，必须基于已完成分析，不等同complete。

解释原则：
- F仅优于R0，不足以排除继续训练和新增输入的作用；
- F优于A但不优于U，不单独支持正常校准；
- F优于U但不优于S，不支持关系—时间监督超越标量强度；
- F优于A/U/S，且预定诊断一致，才支持完整机制；
- 任何论文接收或“高创新”评价都不预先保证。按证据形成结论，不按预期包装结果。
