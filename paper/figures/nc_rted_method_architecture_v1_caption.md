# NC-RTED Method Architecture

**Figure caption.** NC-RTED separates a training-only, source-disjoint teacher from the deployed student. For target fold Q, normal calibration fold C is `(k+1) mod 5` and three remaining source-disjoint folds provide normal references R. Compatible normal calibration windows yield the empirical-tail evidence quality `a`; masked relation-time distances yield `pi`, with rejection masking the auxiliary loss and residual empty mass `1-a`. The student uses the frozen inherited Fast/visual/projector/memory paths, causal RT-DETR observations, existing SigLIP patch pooling, a two-layer width-384 relation-time encoder, evidence-weighted resampling to at most 16 visual tokens, and the existing memory plus Slow LoRA path. Caption processing covers all observed eight-second blocks and aggregates through fixed 16 queries. No-candidate cases bypass the evidence path. A/U/S/F differ only in the displayed auxiliary supervision: A none, U strength-matched global quality, S calibrated `a`, and F calibrated `a` plus `pi`.
